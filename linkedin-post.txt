🔧 Do servidor local à produção: deploy de uma API TypeScript com orçamento zero

Quando decidi construir minha API Financeira, queria algo além de código no GitHub — precisava estar no ar, documentada e funcional de verdade.

O desafio? Fazer deploy de uma stack Node.js + PostgreSQL de graça, sem abrir mão de segurança e confiabilidade.

Depois de debugar problemas de build no Render (compatibilidade do TypeScript 6, devDependencies ausentes, SSL do banco), a API está no ar e funcionando:

→ https://api-financial-279h.onrender.com/api-docs

Destaques técnicos:
• TypeScript 5 + Express 5 + Sequelize
• Arquitetura em camadas com repositories e services
• Autenticação JWT, rate limiting, validação com Zod
• Soft delete e logs de auditoria admin

Stack: Node.js, TypeScript, Express, PostgreSQL, Sequelize, JWT, Zod, Swagger, Render

Aberto a vagas backend no 🇧🇷 Brasil e 🇵🇹 Portugal. Feedbacks são bem-vindos!
